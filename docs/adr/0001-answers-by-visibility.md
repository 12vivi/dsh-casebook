# 0001 答案只发给有权限的 Agent

## 背景

探案游戏最怕泄底。在提示词里写「请勿透露凶手」靠不住：模型看到了答案，就有可能说出来。

## 决定

按可见级别决定每个 Agent 拿到什么，而不是靠提示词约束。

- L1 玩家视角：公开案情、去过的地点、已发现线索的外观、口供。线索板只用这一级。
- L2 当前场景：L1，加上当前地点与可能去的地点里线索的发现条件，以及在场人物的私有档案（秘密、谎话、松口条件）。叙事和书记员用这一级。
- L3 全知：真相、每条线索证明什么、证据链。只有程序计分用；结案后才进入线索板的复盘。

所有按级别取案卷字段的代码都在 `packages/domain/src/game/projections.ts` 一处。

## 后果

- `packages/domain/test/visibility.test.ts` 核对：任何地点、任何输入下，叙事上下文和结算任务里都没有 L3 原文；结案前的线索板里没有 L2、L3 原文。
- 凶手本人在场时，叙事会拿到他自己的秘密，这是扮演他说谎的前提。泄底的剩余风险由 M2 的泄底扫描和书记员标记兜底。
- 叙事会话只追加，凶手出过场以后，他的档案会一直留在叙事的上下文里。
